# hashlist
Hashlist library for C.

# note:

To use the hashlist in your project simply include the headers and hashlist.dll.
There's a main.c included in this repo for you to try and test the library.
Remember that destructors MUST be corresponding to the type of the list item.
Keys are not string for optimisation purposes.
